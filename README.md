# word-ladder

A new four-letter word ladder every day: change one letter at a time to get from the start word to the target, and everyone who plays on the same date gets the same puzzle.

![screenshot](screenshot.png)

*Two moves into the puzzle for 2026-08-10: START at the top, TARGET behind a rule at the bottom, the played chain (WIDE, SIDE, SITE) filling the gap, and on each rung the letter that changed from the rung above set in the accent colour.*

**[Live demo](https://yinggarykairui.github.io/word-ladder/)**

## What it does

Picks one start word and one target word from the 821-word connected core of a hand-written list of 874 common English four-letter words, using the current UTC date as the seed — so the puzzle is the same for everyone on a given date, and the header says which date and that it is UTC. You type a word; it is accepted only if it is on the list, differs from the word above it in exactly one position, and has not already been used, and the rejection tells you which rule you broke. The shortest possible solution is shown as `best possible: N moves` before you start — it is what the puzzle can be done in, not an allowance you have to stay inside — because the puzzle is generated by a breadth-first search from the start word, so a solution of exactly that length is guaranteed to exist. The same number is named the same way everywhere it appears: `solved in 4 moves · best possible 3`. Undo takes back a rung at any point, including after you have solved it — the win belongs to the day, so walking the ladder back leaves the win and the streak standing — the label under the target goes back to `target`, because it names the word under it, and the status line keeps saying `solved today`. Once the ladder reaches the target there is nothing left to add, so the input row is put away and Submit is spent with it — Undo is the only move left, and it brings both back. Reloading keeps the chain you were on, solved or not, and a solve on consecutive days builds a streak stored in your browser. Nothing is sent anywhere: no server, no accounts, no network calls at all.

## How to run

Open `index.html` in any browser. There is no build step, no install, and no dependency — or just use the live demo above. On a screen tall enough to hold it the whole game sits on one screenful and only the ladder column scrolls; on a short one — a phone in landscape — the page scrolls instead.

Playing it, in order, from a cold load: the input is focused when the page opens, so start typing the first word of your ladder and press Enter to play it. That first rung is also what makes Undo live — it is disabled on a fresh puzzle, so from the input Tab reaches Submit and, once a rung is on the board, one more Tab reaches Undo, which takes back the last rung; Shift-Tab walks back the same way, and once the ladder is long enough to scroll, one Shift-Tab past the input reaches the column itself, which arrow keys then scroll — until it is, there is nothing hidden in it and it is not a stop. Turning a phone over is enough to make it one, and it becomes one there and then, without a reload. Keep typing and pressing Enter until you reach the target word at the bottom, where the label turns to `solved`. A finished ladder has no next rung, so at that point the input row is put away — the last word you played sits directly above the target with no empty gap between them, and there is no field left to type a word into that could only be refused. Submit goes away with the field — there is nothing left for it to read, so it greys out and drops out of the tab order rather than sitting there looking live. Undo stays exactly where it was, focused and live: it is the way back if you want to walk a different route, and the first Undo brings the input row, the caret and Submit all back. That is also how a solved board reloads — ladder, target, `solved`, a spent Submit and a live Undo — with nothing focused until you Tab, because there is no field to put the caret in. Case does not matter, accented letters are folded to plain ones, and anything that is not a letter is ignored as you type.

Two extras worth knowing. Adding `?d=2026-01-15` to the URL — any date but today — plays that date's puzzle as a replay: the header says `replay, nothing saved`, it never touches your streak, and nothing it does is stored. `?d=` for today is simply today's game, loaded and saved like any other. A `?d=` that is not a real date says so on the message line and shows today's puzzle. And `tests.html` runs the assertion suite — determinism and a walked shortest solution across 30 consecutive dates, word-list integrity, the input-validation matrix, the streak arithmetic and the corrupt-storage cases — and prints the score. It drives the real page in an iframe, so unlike the game it needs a local server: run `python3 -m http.server` in this folder and open `http://localhost:8000/tests.html`.

## Why it exists

Seeded idea from the factory's warm-start pack (§16-P0): a daily puzzle small enough to finish in one sitting and old enough that a stranger already knows the rules. Word ladders are Lewis Carroll's, from 1877; this one just picks a fresh pair every morning and counts how many mornings in a row you showed up.

Word list: 874 common English four-letter words, written by hand in this repo from scratch — no dictionary file is downloaded, vendored, or fetched at runtime. No fonts, images, or data come from anywhere but these files.
